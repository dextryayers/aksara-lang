# Alat Rilis dan Kompatibilitas

Direktori ini menampung skrip rilis, pemeriksaan kompatibilitas, dan otomasi yang tidak termasuk front end Rust atau runtime C.

- `rilis/`: pembuatan arsip, tanda tangan, dan catatan rilis.
- `kompatibilitas/`: matriks CPython, pengujian ekosistem, dan dashboard.

Alat di sini harus dapat dijalankan tanpa dependensi jaringan kecuali dijadwalkan sebagai job CI khusus.
